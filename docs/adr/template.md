## Context

What forces are at play? What is true today that makes this a decision rather
than an obvious default? State facts, with references to code where they can be
verified. Include the constraints you couldn't change.

## Decision

What was chosen, in the active voice: "we will ...". One decision per ADR.

## Consequences

What becomes true as a result — both directions.

**Good.** What this buys.

**Bad.** What it costs, what becomes harder, what risks are accepted. Be honest;
this half is why the document is worth writing.

**Follow-on work.** Issues this creates.

## Alternatives considered

Each with the reason it lost. An alternative dismissed in one line was probably
not seriously considered — say so plainly if that's the case.

Code, issues, prior art, external discussion.
